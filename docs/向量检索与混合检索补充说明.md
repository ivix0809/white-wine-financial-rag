# 向量检索与混合检索补充说明

## 1. 项目分工

本项目使用 FastGPT 作为实际问答知识库平台，本地 Python
脚本用于财报下载、PDF 文本抽取、页码/章节信息处理和 BM25
检索实验。两部分分工不同，不应把本地 BM25 脚本描述为完整的混合检索实现。

## 2. FastGPT 配置记录

项目配置记录中填写的参数为：

-   知识库索引模型：阿里 emb3
-   检索模式：混合检索
-   语义检索权重：0.3
-   全文检索权重：0.7
-   重排：开启
-   重排模型：gte-rerank-v2

`../screenshots/18_fastgpt_knowledge_base_index_model.png`
展示了知识库页面、10份报告及索引模型"阿里-emb3"。该图可证明界面中显示了索引模型和文档就绪状态，但**不能单独证明混合检索权重、重排设置或某次检索的真实召回结果**。这些还需要在
FastGPT 设置页和搜索测试页补充实际截图。

## 3. 检索思路

-   向量/语义检索：用于寻找语义相关的财报片段。
-   全文检索（BM25式关键词检索）：有助于命中公司名称、财务指标名称、年份等字面信息。
-   重排：对初步召回的候选片段再次排序。
-   回答：只根据检索到的报告内容作答，并记录文件名、页码或其他可回溯出处；材料不足时应明确说明。

## 4. 复核原则

本仓库不新增虚构的向量检索代码，也不把配置文字当作运行证据。现有测试评价和失败分析予以保留。每题的实际输出、来源页码和截图应以
FastGPT
实际运行结果为准；如果某题没有可核验的运行记录，应标明待补，而不是推测答案。
