# 向量检索与混合检索补充说明

## 1. 检索架构

本项目采用混合检索方案完成白酒财报问答知识库：

流程：

财报PDF\
→ FastGPT知识库切块\
→ 向量索引（语义检索）+ 全文检索\
→ 重排模型优化候选结果\
→ 生成带出处答案

## 2. 向量检索配置

实际知识库由 FastGPT 完成向量索引。

配置：

-   Embedding模型：阿里 emb3
-   检索模式：混合检索
-   语义检索权重：0.3
-   全文检索权重：0.7
-   重排模型：gte-rerank-v2

仓库中的 Python 脚本主要用于： - 财报下载 - PDF文本抽取 -
页码/章节信息保留 - BM25检索复现实验

## 3. 为什么同时使用向量检索和BM25

向量检索适合： - 同义表达 - 财务描述语义匹配 - 从财报片段中寻找相关内容

BM25适合： - 公司名称 - 指标名称 - 年份 - 专有名词

两者结合可以提高财报问答的召回效果。
