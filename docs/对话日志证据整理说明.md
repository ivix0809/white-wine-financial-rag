# 对话日志证据整理说明

## 这份日志能证明什么

本项目收到一份 FastGPT 对话导出
CSV。整理时仅保留与作业有关的用户问题、助手最终回答文本、回答中明确出现的页码和
`CITE` 来源 ID，并按原有 10 道测试题映射到
`tests/dialogue_log_evidence.csv`。

原始导出文件包含使用者标识、IP/属地信息，以及名为 `reasoning`
的字段。为避免不必要地传播个人标识和内部分析内容，整理版不复制这些字段；只保留用户问题和最终输出文本。

## 这份日志可以补强的交付项

-   Q1--Q7、Q9--Q10：日志里能找到相应问题和实际最终回答；多个回答包含
    `CITE` 来源 ID，部分明确标注报告页码。
-   Q3：日志里包含舍得酒业经营活动现金流量净额的实际回答及合并/母公司口径说明，可补充原来缺少输出截图的问题。
-   Q8：日志明确显示用户问的是"金徽酒"，但回答仍沿用了"老白干酒"的上一题内容。这是很有价值的真实失败证据，应保留，而不是删除。
-   Q9：日志明确说明跨公司收入增速题仅确认舍得酒业，未覆盖另外9家公司，支持原来的召回不足分析。
-   Q10：日志回答引用了舍得、山西汾酒、伊力特、今世缘、迎驾贡酒、水井坊、老白干酒等公司的材料，但最终回答没有逐家公司提供明确页码，仍需展开引用详情补齐。

## 这份日志不能单独证明什么

-   日志没有为每一轮保存检索方式、语义/全文权重、重排参数。
-   `CITE` ID 是引用标记，不等于已经展示了完整的召回原文块。
-   有些答案只给了引用 ID，没有明确页码；这类题仍需在 FastGPT
    里点开引用详情核验。
-   Q1
    的多轮回答曾出现不同口径：营业总收入922.78亿元、财务报表附注口径约496.61亿元，以及"财务报表相关科目变动分析表"口径约907.03亿元。整理版保留最后一轮答案，同时标明此前存在口径差异，不能把三个数合并成同一指标。

## 下一步

2.  至少为 Q2 截取一张真实召回结果图，显示原文、报告名称和页码。
3.  截取 Q2 的最终回答与引用详情。
4.  对 Q5、Q6、Q10 等未明确页码的题目，打开 `CITE` 引用核验页码和原文。
5.  重新运行 Q8
    时可以记录新结果，但旧的上下文串扰失败必须保留在实验记录中。

**结论：** 对话日志是补充实际运行输出的有效证据，尤其补足了 Q3 的回答和
Q8 的失败案例；但它不能替代混合检索设置截图和真实召回块截图。
