# 白酒行业2026年半年报问答知识库——实验结论

本次作业选取贵州茅台、山西汾酒、舍得酒业、水井坊、老白干酒、今世缘、迎驾贡酒、口子窖、金徽酒和伊力特共10家白酒上市公司，收集其2026年半年度报告全文，并基于 FastGPT 搭建财报问答知识库。知识库采用分块存储方式，将标题加入索引，并使用“语义向量检索 + 全文检索”的混合检索方式，其中语义检索权重为0.3、全文检索权重为0.7，同时使用 gte-rerank-v2 对候选结果进行重排。

共设计10道测试题，其中8道为单公司问题，2道为跨公司全景问题。测试结果为：6道回答正确，2道部分正确，2道错误。单公司、单指标的数字题和事实题整体表现较好；跨公司问题和需要跨多个章节整合的信息更容易出现召回不足。

实验中发现三类典型问题：第一，财报中存在“营业收入/营业总收入”“合并/母公司”等近似口径，可能导致错误召回；第二，跨公司全景问题的答案分散在多个文档中，普通Top-K检索容易漏掉部分公司；第三，多轮对话中可能出现上一题公司的内容串入下一题的上下文串扰。

结论是：普通RAG比较适合单公司、单指标、答案位置相对集中的财报问题；对于跨公司、多章节的全景问题，需要进一步增加公司过滤、逐公司检索后汇总、结构化财务数据，或采用Agentic检索/知识图谱等方式提升完整性。
